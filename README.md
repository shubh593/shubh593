### 🚀 About Me

I am an AI & Data Science engineer focused on designing autonomous, high-impact intelligent systems. My technical spectrum spans **Multi-Agent Orchestration**, **Retrieval-Augmented Generation (RAG)**, **Deep Reinforcement Learning for Quantitative Trading**, and **Computer Vision**.

- 🛸 **Ecosystem & Workflows**: Prototyping, evaluating, and operating multi-agent systems with **Antigravity** and the **Model Context Protocol (FastMCP)**.
- 🤖 **Autonomous Multi-Agent Systems**: Architecting multi-agent networks (Data Scout, Strategist, Risk Manager, Auditor, Notifier) for real-time market analysis and automated decision execution.
- 📚 **Generative AI & RAG**: Building production-grade clinical and domain-specific knowledge retrieval engines using **LangChain**, **Pinecone Vector Database**, and **Sentence-Transformers**.
- 📈 **Quantitative & Financial AI**: Engineering automated SIP portfolio rebalancing engines and Deep RL trading agents (PPO, Gymnasium) with risk-adjusted metrics (Sharpe ratio, max drawdown constraints).
- 🌐 **Full-Stack Intelligent Apps**: Crafting reactive interfaces and data visualization dashboards using **Next.js 16**, **React 19**, **Tailwind CSS v4**, and **TradingView Lightweight Charts**.
